# MyPartySystem
디아프 수업용 p5.js 파티클 프로젝트입니다. 문자 입자로 만든 3D 크리스마스트리가 회전하며 반짝입니다.

- `index.html`을 브라우저에서 열어 실행합니다.
- `Particle.js`: 문자 입자의 3D 회전, 투영, 색상 표현
- `ParticleSystem.js`: 원뿔 트리 생성과 깊이 기반 문자 겹침 처리
- `sketch.js`: 눈, 별, 인사말, 애니메이션 (문구는 `GREET`, 회전 속도는 `SPIN`으로 변경)
- 하단 버튼으로 일시정지하거나 재생할 수 있습니다.
- 코드 에디터 패널은 렌더링 흐름을 보여주는 장식용 예시입니다.

- 이 프로젝트의 호스팅 주소 : https://metakits.cc/MyPartySystem/
